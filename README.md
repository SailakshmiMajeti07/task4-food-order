# 🍔 Food Ordering Web Application

A full-stack Food Ordering Web Application built using **PHP, MySQL, HTML, CSS, Bootstrap, and XAMPP**.

## 🚀 Project Links

**GitHub Repository:**  
https://github.com/SailakshmiMajeti07/task4-food-order

**Run Project (Localhost):**  
http://localhost/task4-food-order/login.php

## ✨ Features

### User Features
- User Registration
- User Login Authentication
- Secure Password Hashing
- Session Management
- Browse Available Foods
- Place Food Orders
- Logout

### Admin Features
- Admin Panel
- Add Food Items
- Edit Food Items
- Delete Food Items
- View Customer Orders
- Image Upload

## 🛠 Technologies Used

- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- XAMPP
- GitHub

## ⚙️ Database

**Database Name:**  
```sql
food_order_db
```

**Tables:**  
- users
- foods
- orders

## ▶️ How to Run

1. Start Apache & MySQL in XAMPP
2. Open phpMyAdmin
3. Create database: `food_order_db`
4. Place project in:

```bash
C:\xampp\htdocs\task4-food-order
```

5. Run:

http://localhost/task4-food-order/login.php
